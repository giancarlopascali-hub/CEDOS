CEDOS Auto: local folder workflow

This guide is for testing a closed experiment cycle on one computer. CEDOS generates proposals; the folder exchange writes a CSV for each proposed batch and waits for measured objective values.

1. Start both local processes

Start CEDOS with run_cedos.bat. The server window shows its URL, normally http://127.0.0.1:5002. In another PowerShell window, from the CEDOS folder, run:

.\.venv\Scripts\python.exe imex\cedos_imex.py --server http://127.0.0.1:5002

Use the server window's actual URL if it selected another port. The exchange creates imex/proposals and imex/results.

2. Configure and start Auto

  1. Choose BO or TransBO with the TransBO toggle. The optimizer choice stays fixed for this campaign.
  2. Enable Auto. Start from DoE to create an initial experiment batch, or start directly from the active optimizer with an existing measured dataset.
  3. Review features, objectives, bounds, constraints, prior targets if using TransBO, and stopping conditions. After a DoE batch is measured, Auto pauses for optimizer review before its next proposal.
  4. DoE, BO, TransBO and SA Setup CSV files hold configuration only. They do not transfer measured rows or TransBO Prior Targets.

3. Return measured results

  1. Find the new Proposal_...csv and matching .json manifest in imex/proposals. The proposal CSV contains a row_id for each suggested experiment.
  2. In imex/results, open the matching Results_...csv.example file. Enter finite numeric values for every objective without changing row IDs or proposed feature values.
  3. Save a copy as the same filename without .example, ending in .csv. The exchange sends it to CEDOS. An accepted file receives the SENT_ prefix.
  4. CEDOS merges only results that match the active campaign, proposal and row IDs. It then checks stopping conditions using the newly measured objectives.
Safe retries: The exchange writes each proposal once and acknowledges it after the files exist. If a result submission is interrupted, leave the unsent result CSV in place and let the exchange retry.

Local test limits

The CEDOS folder exchange supports files only. The previous AutoEDOS IMEX desktop program uses an older protocol; serial, network and USB hardware receive paths are outside this local build. A CEDOS server restart clears its in-memory Auto campaign, so start a new campaign after restart. Save your dataset CSV before closing the browser.

TransBO's source optimizer cannot enforce numerical feature constraints throughout its fitted GP path or filter historical duplicates there. CEDOS blocks those unsupported constraint settings and disables the duplicate toggle.
